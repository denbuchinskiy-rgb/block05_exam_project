# Блок 6. Финальный проект DataAnalyzer
 
## Цель
 
Собрать в VS Code проект анализа данных на Python и подготовить датасет к машинному обучению.
 
## Датасет
 
D:\dev\block05_exam_project\data\sales_data.csv
 
## Что делает проект
 
1. Загружает CSV-датасет.
2. Проверяет структуру данных.
3. Очищает пропуски и дубликаты.
4. Считает статистики NumPy/Pandas.
5. Строит групповые отчёты.
6. Строит графики.
7. Создаёт новые признаки.
8. Кодирует категориальный столбец `ocean_proximity`.
9. Делит данные на train/test.
10. Сохраняет подготовленные файлы для будущего машинного обучения.
 
## Как запустить
 
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
python -m pytest -q
```
