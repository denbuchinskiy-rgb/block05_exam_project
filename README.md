# Экзаменационный проект блока 5

## Тема

Анализ данных в Excel и Python.

## Цель проекта

Показать, как данные из Excel можно обработать, очистить,
проанализировать и визуализировать средствами Python.

## Что используется

- Excel
- Python
- pandas
- matplotlib
- VS Code
- GitHub

## Как запустить проект

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Что делает проект

1. Загружает Excel-файл.
2. Очищает данные.
3. Создаёт вычисляемые столбцы.
4. Считает отчёты.
5. Создаёт сводную таблицу.
6. Строит графики.
7. Сохраняет итоговый markdown-отчёт.

## Связь Excel и Python

Excel удобен для визуальной работы с таблицей.
Python удобен для повторяемого анализа, автоматизации,
очистки данных и подготовки отчётов.
