# Блок 7. Экзаменационный проект по регрессии
 
## Тема
Прогнозирование количества проданных единиц товара по данным продаж.
 
## Цель
Собрать проект машинного обучения в VS Code:
- загрузить Excel-датасет;
- подготовить признаки;
- обработать даты и категориальные признаки;
- обучить модель регрессии;
- посчитать MAE, MSE, RMSE, R2;
- построить графики;
- сохранить отчёт;
- загрузить проект в GitHub.
 
## Датасет
Файл: data/sales_data.xlsx  
Лист: sales_data
 
## Целевая переменная
quantity — количество проданных единиц.
 
## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
python -m pytest -q
```
